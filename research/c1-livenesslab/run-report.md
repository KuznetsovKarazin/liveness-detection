- Independent unit / train-dev-test counts: unit = image (still frames of webcam sessions). Evaluation: 150 bona fide + 150 attacks from the official test set (3,362 bona fide, 5,761 attacks), sampled at a constant step over the official lists; bona fide from 9 subjects, attacks from 15. Training of the four reference CNNs: official train split, 2,507 train / 493 validation (validation by subject) / 3,000 test images (`checkpoints/*.json`).
- Subject, session, video overlap and duplicate checks: the official NUAA split shares subjects 1–9 between train and test (different sessions); the evaluation images are all from the official test lists, never seen in training by the *official* checkpoints. The *pooled* NUAA checkpoints (random 80/20 over all images) share subjects and sessions with these images and are therefore excluded from the table. No duplicate hashes in the manifest.
- Label mapping / score direction: 0 = bona fide, 1 = attack; score = probability of attack (larger = more likely attack), as stored in the cache and in `scores.csv`.
- Crop, resize, orientation, channel order, normalization: CNN rows: image decoded by OpenCV `imdecode` (BGR; the 300 NUAA images carry no EXIF orientation tag, so no rotation is involved), face detected by RetinaFace, square crop with 15 % margin, resize to 256×256 (area interpolation), conversion BGR→RGB, then the reference enhancement in RGB (bilateral filter 9/75/75, CLAHE 3.0 on L of Lab, unsharp mask 1.5/−0.5 σ 2, gamma 1.2, linear scale α 1.1 β 5), float32 scaled to [0, 1], fed to the model as RGB (as the reference dataset loader does). Other analyzers use their own crop (`CROP` per module) documented in the application's "i" cards and in the technical specification.
- Model selection, threshold selection and calibration: no model selection on the test data; threshold fixed a priori at 0.5 on the attack probability, no calibration.
- Attack decision at threshold (including equality): attack if score > 0.5; equality counts as bona fide.
- Source-only development rule for external targets: not applicable to this run (same-dataset evaluation for the reference rows); cross-dataset rows use the same fixed threshold without any adaptation to the target.
