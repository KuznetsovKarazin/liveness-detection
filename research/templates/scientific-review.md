# Scientific review

## Evidence map
| Publication / claim | Original code or archive hash | Dataset / split | Checkpoint | Command | Result table | Evidence status |
|---|---|---|---|---|---|---|

Evidence status: verified correspondence / missing material / hypothesis.

## Checks
- Metric formulas, score direction, threshold equality and missing-class behavior.
- Official splits, subject/session/video separation and duplicate handling.
- Crop/resize/channel order/normalization and train-inference consistency.
- Checkpoint origin, training sources and any exposure to evaluation targets.
- Table generation, sample counts and discrepancy from recorded results.

## Findings and correction plan
| Confirmed defect or unresolved question | Evidence | Affected version/results | Correction | Verification | Priority |
|---|---|---|---|---|---|

## Baseline decision
Identify the checkpoint, protocol and commands suitable for the first controlled pilot. Record unresolved issues that block larger experiments. A defect in current code does not, without matching evidence, establish a defect in a published experiment.
