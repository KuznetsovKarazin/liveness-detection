- Limitations / failed checks: fixed threshold 0.5 chosen a priori for the table; image-level counts with correlated frames; NUAA not subject-disjoint by design; single seed; the source-dev threshold is an exploratory calibration: two dev subjects, dev images already used for early stopping, and the dev scores separate the classes completely, so every threshold in [highest bona fide score, lowest attack score) has zero dev error and the dev set does not identify a unique threshold.
